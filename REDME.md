# 🏠 California House Price Prediction using Linear Regression

## 📌 Project Overview

This project uses the **Linear Regression** machine learning algorithm
to predict the median house value in California.

The model is trained using housing, geographical, demographic and
income-related features from the California Housing dataset.

The complete machine learning workflow is implemented in Python
using Google Colab.

---

## 🎯 Objective

The main objective of this project is to build a Linear Regression model
that can predict California house prices based on different
housing-related features.

---

## 📊 Dataset

The dataset contains information about California housing.

### Features Used

- `longitude`
- `latitude`
- `housing_median_age`
- `total_rooms`
- `total_bedrooms`
- `population`
- `households`
- `median_income`

### Target Variable

- `median_house_value`

---

## 🛠️ Technologies & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

---

## 🤖 Machine Learning Algorithm

### Linear Regression

Linear Regression is a supervised machine learning algorithm used
to predict a continuous numerical value.

In this project, it is used to predict the median house value.
